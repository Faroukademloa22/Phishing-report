# Phishing-report
Phishing email analysis report
This repository contains a phishing email analysis report from emails collected between 2022–2024 for security awareness and training purposes.

**What’s Inside**
A PDF report: Series of phishing email analysis on phishing pot.pdf

Step by step analysis of real phishing emails; Email header & metadata checks, URL and attachment scans, Identifying Indicators of Compromise (IOCs), Key phishing techniques (spoofing, malware delivery, credential theft), Recommendations to prevent phishing attacks
